# Sudoku

A clean, quiet Sudoku. Three levels (Kid, Easy, Hard), light and dark mode, installable as an app, works offline.

Plain HTML, CSS and JavaScript. No build step.

- Every puzzle is generated on the device and has exactly one solution.
- Notes, undo, erase, hint, auto-pause, saved progress, best times.
- Install: Chrome / Android show an install button; on iPhone use Share, then Add to Home Screen.

Hosted on Cloudflare Pages.
